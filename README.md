# 🎬 CineYatra · சினி யாத்திரை

> *Your personalised world cinema journey — வணக்கம், Shalini!*

A mood-aware, time-aware movie recommender built for **Shalini (@rsshalini)** — curated across 5 world cinemas with Rotten Tomatoes ratings, analytics, and a hand-picked "For You" shelf.

---

## ✨ Features

- **🌸 For Shalini shelf** — 20 hand-curated picks matching bold, nostalgic, analytical, romantic & chill taste
- **🔪 Mood Quick-Picks** — Thrill me · Romance me · Let me cry · Epic night · Scare me · Chill evening
- **🌍 5 World Cinemas** — Indian (Tamil-first) · Hollywood · Korean · Japanese · Chinese
- **🍅 Rotten Tomatoes ratings** — Tomatometer + Audience score on every card
- **📊 Live Analytics** — Real-time view tracking with country detection
- **💬 Natural language search** — Ask in your own words
- **⏰ Time + mood aware** — Recommendations shift based on day and time

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:5173/cineyatra/](http://localhost:5173/cineyatra/)

## 🛠 Tech Stack

- **React 18** + **Vite 5**
- **Persistent Storage API** (Claude artifacts) for analytics
- **ipapi.co** for geo-IP country detection
- No external UI libraries — pure CSS-in-JS
